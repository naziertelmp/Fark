# PlixWin

PlixWin is a free and open-source solution

## Features

- 🖥️ Full Windows environment on demand
- 🔒 Secure TCP tunnel
- 📱 Works from any device: Windows, macOS, Linux, Android, iOS
- ⚡ Lightweight and easy to set up
